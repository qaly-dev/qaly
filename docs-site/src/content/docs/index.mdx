## Why Qaly?

Traditional mobile test tools were built for humans writing brittle selectors.
Qaly was built for AI agents: natural-language selectors, event-driven waits with no flakiness,
and a replay engine that is **7× faster** than any ADB-based tool.

Works with any Android app — native, React Native, Jetpack Compose, or Flutter.

## How it works

1. **Record** — your AI agent (via MCP) taps through the app, and Qaly saves a `.qaly.test` file + recordings in `.qaly/`.
2. **Replay** — `qaly-test my.qaly.test` runs all tests deterministically, no LLM needed. CI-ready.
3. **Heal** — when UI changes break a step, Qaly's self-healing engine finds the right element and updates the recording.

## Quick start

```sh
# Install
brew install qaly-dev/tap/qaly

# Add to Claude's MCP config
echo '{"mcpServers":{"qaly":{"command":"qaly-mcp","env":{"ADB_BINARY":"/path/to/adb"}}}}' > ~/.config/claude/mcp.json

# Run an existing test
qaly-test my.qaly.test
```
